# V2 verification

Executed November 2, 2026 against the delivered V2 source.

## Automated checks

- **6,965 engine/data assertions passed:** all 1,080 words reachable without premature repeats; category pools exhaust/reset correctly; selected categories and recent-category avoidance work; all group sizes 3–25 and legal Imposter counts; default scaling; legacy category/word migrations; unchanged Question content and role selection under matching seeded inputs.
- **2,051 starter assertions passed**, including **500,000 full simulated rounds** using Web Crypto, both modes, and 3/5/8/12/25 players. Every possible starter at every supported count, rejection boundaries, independent inputs, and repeated starters were checked. See RANDOMIZATION.md and the JSON results.
- **934 DOM/screen assertions passed:** complete Classic rounds at 3/8/15/25 players and Question rounds at 3/12/25; Person 3 first; matching shared words/hints; exactly one alternate question; identical Question markup after excluding the actual question and Person number; identical locked-card classes; no reopened secrets; results confirmation/cancellation; immediate double-click guard; fresh replay; five distinct rounds; category controls; blocked storage; file-URL history; safe refresh; browser history events; background privacy; end-round navigation.
- Every runtime JavaScript file passed syntax checking. HTML/manifest resources exist. The unchanged Question database is byte-for-byte identical to the latest prior version.
- Data validation confirms 1,080 unique nonempty Classic entries, 45 categories of 24 entries, 200 unique Question IDs, and distinct original/alternate prompts. Word labels and category order are unchanged. No hint contains its complete secret word, ignoring case.

The DOM suite uses jsdom with scrolling and dialog display primitives stubbed. It runs the actual application code; it is not a substitute for every device/browser combination.

## Limits and next check

No physical iPhone or Android device was used, and individual Safari/Chrome/Windows builds were not all run. File-URL behavior passed the DOM test. The live browser tool rejected file:// URLs under its security policy, so direct opening was not browser-tested; a physical Mac Safari check remains useful. GitHub publication was not performed. Hint difficulty is editorial and should be refined after live group play.

After deploying to the existing Pages URL, play one complete round in each mode on your actual phone, reload during a reveal, and check the home-screen shortcut. Keep Person numbers consistent across rounds for the existing Imposter-fairness history.
